# Preprence Design System

## Brand

Name: Preprence

Meaning:
Preparation + Experience

Hero:
Know the interview before you face it.

Tagline:
Read real interview experiences shared by students from your college.

## Product Personality

Preprence should feel:

- Trustworthy
- Practical
- Modern
- Student-friendly
- Calm
- Credible
- Community-driven

Preprence should NOT feel:

- Corporate
- Overly playful
- Like a generic job portal
- Like an AI/SaaS landing page
- Like a college administration website

---

## Visual Direction

Overall style:

Minimal editorial + modern product UI.

The interface should prioritize:

- Information
- Readability
- Trust
- Specificity
- Whitespace
- Clear hierarchy

Use:

- Generous whitespace
- Strong typography
- Subtle borders
- Restrained shadows
- Small amounts of accent color
- Clean layouts
- Consistent spacing

Avoid:

- Excessive gradients
- Glassmorphism
- Excessive shadows
- Excessive rounded cards
- Stock photography
- Decorative 3D illustrations
- Excessive animations
- Floating particles
- Generic SaaS visual patterns

Do not put every section inside a card.

Cards should represent an independent piece of information.

---

## Typography

Primary font:

Geist

Use Geist consistently throughout the application.

Typography should provide most of the visual hierarchy rather than
large decorative graphics.

Headings:

- Strong
- Clear
- Slightly tight
- Not excessively heavy

Body:

- Comfortable reading width
- Relaxed line height
- High readability

---

## Color Direction

Primary palette:

- Warm off-white
- Deep charcoal
- Muted gray
- Teal accent

The interface should remain predominantly neutral.

Teal is an accent, not a background color.

Use teal for:

- Primary actions
- Important interactive states
- Links where appropriate
- Selected states
- Small visual accents

Do not use teal everywhere.

Semantic colors:

- Green → positive/success
- Amber → warning
- Red → destructive/error

Semantic colors should remain restrained.

Do not introduce additional brand colors without an explicit design decision.

---

## Landing Page Background

The landing page should use a warm off-white base.

Use a very subtle geometric/grid or structured-line pattern.

The pattern must be:

- extremely subtle
- low contrast
- non-distracting
- decorative rather than informational

A single subtle teal radial glow may be used behind the hero.

Do NOT use:

- large colorful gradients
- purple/blue/pink gradients
- photographs
- busy illustrations
- animated particle backgrounds

The background should support the content rather than compete with it.

---

## Layout

Use generous whitespace.

Prefer:

- clear content widths
- strong alignment
- simple sections
- readable line lengths
- consistent vertical rhythm

Do not make every section full-width.

Desktop layouts should generally use a centered content container.

Mobile layouts must be designed intentionally rather than simply
shrinking desktop layouts.

---

## Border Radius

Use moderate, consistent corner radii.

Avoid extremely rounded/pill-shaped containers unless the component
naturally calls for a pill, such as:

- status badges
- tags
- filters

Do not make every card look like a large rounded floating object.

---

## Shadows

Use shadows sparingly.

Prefer:

- borders
- contrast
- whitespace

over heavy drop shadows.

Cards should generally feel grounded in the page rather than floating.

---

## Buttons

There should be a clear hierarchy.

Primary:

- Teal
- Strong contrast
- Used for the main action

Secondary:

- Neutral/outlined
- Used for supporting actions

Destructive:

- Reserved for destructive actions
- Do not make destructive actions visually dominant by default

Buttons should have consistent:

- height
- padding
- radius
- typography
- hover state
- focus state
- disabled state

---

## Cards

Cards should be used intentionally.

Experience cards should prioritize:

1. Company
2. Role
3. Candidate context
4. Verdict
5. Interview process summary
6. Useful metadata

Company cards should prioritize:

1. Company identity
2. Experience count
3. Relevant metadata

Avoid unnecessarily putting cards inside cards.

---

## Interview Rounds

Interview rounds are an important visual concept of Preprence.

Where appropriate, represent the interview process as a structured
sequence/timeline.

Example:

01 → Online Assessment
02 → Technical
03 → HR

The round structure should feel distinctive and consistent across
the application.

---

## Information Hierarchy

For an interview experience:

Level 1:
Company + Role

Level 2:
Degree + Graduation Year + Verdict + Interview Date

Level 3:
Interview process / rounds

Level 4:
Round details, questions, duration, difficulty

Level 5:
Overall tips and additional information

The interface should make the most useful information easy to scan.

---

## Responsive Design

Preprence is mobile-first.

Every page must work well at:

- Mobile
- Tablet
- Desktop

Do not simply compress desktop layouts.

On mobile:

- prioritize content
- reduce decorative elements
- preserve readable typography
- maintain comfortable touch targets
- avoid horizontal overflow

---

## Component Consistency

Reuse existing components whenever possible.

Do not create a new visual pattern when an existing component can be
extended.

Do not create multiple visually different versions of:

- buttons
- cards
- inputs
- badges
- dialogs
- page containers

New components should follow the existing design tokens.

---

## Animation

Animation should be subtle and purposeful.

Use animation only when it improves:

- feedback
- navigation
- understanding
- perceived responsiveness

Avoid:

- constant movement
- distracting background animation
- excessive entrance animations

Respect reduced-motion preferences.

---

## Core Principle

Preprence is a knowledge platform, not a marketing website.

The interface should make real interview information easy to discover,
read, understand, and contribute.

When in doubt:

Choose clarity over decoration.
Choose consistency over novelty.
Choose information over visual noise.
